
# Metasploitable 2 & Mutillidae II Setup Project

## Description
This project demonstrates the installation, configuration, and successful deployment of Metasploitable 2 and Mutillidae II vulnerable web application using VMware Workstation.

## Environment
- Host OS: Windows
- Virtualization: VMware Workstation
- Target VM: Metasploitable2-Linux
- Web App: Mutillidae II

## Steps Covered
- VMware installation
- Metasploitable import
- Apache & MySQL service startup
- Network configuration
- Database error fixing
- Mutillidae II browser access

## Access URL
```
http://<metasploitable-ip>/mutillidae
```
